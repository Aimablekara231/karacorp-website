# KaraCorp Website Assets

This folder is reserved for brand and media assets used by karacorp.org.

- Replace placeholder partner text badges in the HTML when official logo files are available.
- Keep file names lowercase and descriptive.
- Preferred image formats: SVG for logos and WebP/PNG for social preview or photography.
- Hero visuals are code-native in `css/styles.css`, so the site has no required hero image dependency.
