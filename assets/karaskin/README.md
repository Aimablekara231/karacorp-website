# KaraSkin Product Images

Use this folder for KaraSkin product photography.

Recommended workflow:
- keep product images in this folder
- update `js/karaskin-products.js` to point each product to its image path later
- push to GitHub and redeploy

Suggested pattern:
- `assets/karaskin/clarity-cleanser.jpg`
- `assets/karaskin/glow-renewal-serum.jpg`
- `assets/karaskin/repair-body-butter.jpg`
- `assets/karaskin/radiance-cleansing-bar.jpg`
- `assets/karaskin/routine-starter-bundle.jpg`
- `assets/karaskin/custom-gift-box.jpg`

Right now the storefront uses styled fallback media blocks, so the page still works before photography is added.
