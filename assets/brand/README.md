# KaraCorp Official Logo

Place the official PNG logo file here and keep this exact name:

- `karacorp-logo.png`

Full path:

- `assets/brand/karacorp-logo.png`

Once the file is added:
- header branding updates automatically
- footer branding updates automatically
- favicon and Open Graph logo references point to this file
- the current `KC` fallback mark disappears

Recommended:
- use the original exported PNG from your designer
- keep the background exactly as approved if you want it shown as-is
- use a high-resolution version so it stays sharp on large screens
